# Open Questions — Career Paths

No blocking questions.

- **A career path = a target role + an ordered list of required skills**, each skill resolved to whichever Learning Path or Course already builds it (reuses [Skills](../16-skills/)' tagging, doesn't duplicate it). The builder doesn't create new content — same "own the structure" principle as Learning Paths.
- **Learner-facing home:** a new "Career Paths" item is needed in the Learning-mode nav (same refinement pattern as Dashboard and Skills before it) — flagged here, not silently added to Shell.
- **No org-chart / role-hierarchy modeling** — a career path is just a named target (e.g., "Senior Account Executive"), not tied to an actual reporting structure. Real value, real added complexity — deferred.
