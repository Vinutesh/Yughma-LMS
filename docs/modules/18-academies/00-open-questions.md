# Open Questions — Academies

No blocking questions, but one deliberate course-correction:

- **No new Learning-mode nav item this time** — Dashboard, Skills, and Career Paths have each already added one to the Shell's originally-approved 5-item sidebar; a fourth addition risks exactly the cluttered-nav problem the product vision explicitly wants to avoid. Instead, Academies surface as a **filter/section inside the existing Courses Catalog tab** ("Browse by Academy") — visibility without another permanent nav slot. Worth a consolidated Shell nav review once Phase 3 wraps, given how many additions have accumulated.
- **An Academy is a named, curated collection of existing Courses/Paths** with a title, description, and hero image — no new content authoring, same "structure, not content" principle as Learning Paths and Career Paths.
- **No per-academy custom branding** (colors/logo) — consistent with the earlier decision that per-org branding itself is deferred to Phase 4; an academy is even more clearly not the place to introduce visual customization first.
