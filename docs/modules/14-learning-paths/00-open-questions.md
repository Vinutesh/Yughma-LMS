# Open Questions — Learning Paths

No blocking questions — narrowing applied:

- **A path is a simple ordered sequence of existing courses** — not a separate content-authoring surface. The Path Builder reorders/adds/removes references to already-built Courses; it doesn't create new content, matching the same "own the structure, not the content" principle used for Course Builder → Lessons.
- **Sequential by default, not configurable branching** — course 2 unlocks after course 1 is complete, straight down the line. Branching/conditional paths ("if you scored X, take Y instead") are real L&D value but real added complexity — deferred.
- **My Paths + Path Catalog is one screen, two tabs** — same tabbed pattern as Courses.
- **Path detail (learner) reuses the Course detail layout's tree/progress pattern**, one level up — a path is a tree of courses the same way a course is a tree of lessons, so the same visual language applies.
