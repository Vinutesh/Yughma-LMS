# Module 00 — Cross-Cutting Shell

The app frame every other module lives inside: primary navigation, top bar, org switcher, command palette, notifications, profile menu, and global system screens (404/500/maintenance/offline). Scoped in [MODULES.md](../../MODULES.md) §0.

This is the first module through the full design sequence, per [ROADMAP.md](../../ROADMAP.md) Phase 0 — every other module's layout depends on decisions made here.
